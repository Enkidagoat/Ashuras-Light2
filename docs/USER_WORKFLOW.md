# User Workflow — Ashura's Light 2

**Status:** Defined from owner directive. Technical details UNRESOLVED.

## Intended users
Mission planners, educators, and public users.

## Primary workflow
1. User selects a lunar south-pole candidate site by coordinates.
2. User selects a date and time.
3. Application displays Sun azimuth and elevation relative to the local lunar horizon.
4. Application displays Earth azimuth and elevation relative to the local lunar horizon.
5. User may select a second site or second date/time for comparison.
6. Every result is accompanied by provenance and explicit limitations.

## Required explanations on every result
- What the user is looking at
- Where the information came from
- What it means (geometric centre-direction only)
- What it does not mean (not usable power, not operational communications, not terrain-masked)
- What to do next

## Unresolved
- Exact coordinate entry method
- Exact comparison presentation
- Whether horizon-relative visualization is numeric only or includes a simple diagram
