# Technical Architecture — Ashura's Light 2

**Status:** UNRESOLVED.

No architecture will be proposed until product requirements are defined by the owner.

## Constraints that will apply once requirements exist
- Clear separation of presentation, application logic, and data processing.
- Deterministic calculations where practical.
- Explicit input validation.
- Reproducible outputs.
- Traceable data provenance.
- No decorative 3D.
- No mock data presented as real data.
- No unsupported scientific claims.

Implementation is not authorized until Phase 1 requirements are established.
