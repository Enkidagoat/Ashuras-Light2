# Technical Architecture — Ashura's Light 2

**Status:** Constraints established. Architecture UNRESOLVED pending Phase 1 acceptance.

## Constraints that apply
- Clear separation of presentation, application logic, and data processing.
- Deterministic calculations where practical.
- Explicit input validation.
- Reproducible outputs.
- Traceable data provenance.
- Documented coordinate systems, units, epochs, and limitations.
- No decorative 3D.
- No mock data presented as real data.
- No unsupported scientific claims.
- No code copied from previous Lunar Navigator or Ashura's Light repositories.

## Unresolved
- Calculation path (ephemeris service vs local computation)
- Hosting approach
- Specific libraries or frameworks

Implementation is not authorized until the Project Owner explicitly accepts Phase 1.
